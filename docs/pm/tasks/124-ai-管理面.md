# 任务书 · #124 AI 管理面（第一段：后端骨架）

> **为什么有这份任务书**：派活消息是「唯一发给模型的那句话」⇒ 太长会撑爆上下文
> （实测：一条超长任务消息让子会话探索了 67 步、最后被输出上限截断 ⇒ 整个会话作废）。
> ⇒ **细节进仓、派活消息只留指针**。

## 0. 这一段做什么 / 不做什么

**做**（本 PR 的全部）：

- **智能体配置落库**（不是配置文件！⇒ 容器里 `agents/` 是打进镜像的只读层 ⇒ 运行时写文件不成立）
- 智能体 **CRUD** 的 HTTP 接口（创建 / 列表 / 详情 / 修改 / 删除）
- **审计**：每次创建/修改进审计（沿用 `core/audit/` 的语义 ⇒ 能查「谁在什么时候改了什么」）
- **权限边界**：普通用户只能读写**自己的**智能体；admin 可以管全部
- **单测** + 一条**静态 e2e** 断言

**不做**（留给后续几条，别越界）：

- 技能管理、MCP 池、前端页面、市场列表/搜索/排序/分页、模板复制
- 跨机安装包、社区分享、评分评论、多租户组织

## 2. 数据模型（**只加不改**）

新表 `ai_agent`（共享库 ⇒ **只允许新建表 + 加可空列 + 加外键**）：

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| `id` | string | 主键 |
| `name` | string | 智能体名（**用户可见**） |
| `description` | string? | 描述 |
| `slug` | string | 唯一标识（`@ai-admin/dsh` 的路由名用它 ⇒ **小写字母/数字/中划线**） |
| `model` | string? | 覆盖全局默认模型（不填 ⇒ 用全局） |
| `system_prompt` | string? | 自定义系统提示词（⚠️ 是**提示词** ⇒ 进模型上下文 ⇒ 只许本人/admin 改） |
| `mcp_server_ids` | string? | JSON 数组：本智能体选用哪些 MCP（**第二段做** ⇒ 这一段先留空） |
| `skill_ids` | string? | JSON 数组：本智能体选用哪些技能（**第二段做** ⇒ 先留空） |
| `owner_id` | string | 属主（来自请求的 JWT 用户 id） |
| `visibility` | string | `private` / `market`（**市场在第二段** ⇒ 这一段只写 `private`） |
| `created_at` / `updated_at` | datetime | |

⚠️ **迁移规矩**（共享库 ⇒ 事故就是删表）：

- 用**离线** `prisma migrate diff --from-schema-datamodel` 生成（**不做 drift 检查**）；
- 迁移文件里**不许**出现 `DROP` / `TRUNCATE` / `RENAME` / `MODIFY` / `DELETE FROM`（照 #121 的安全阀做法）；
- **不许**用 `prisma migrate dev` / `prisma migrate reset`（它们在共享库上会要求 `DROP DATABASE`）。

## 3. 接口（`core/routes/` 下，成体系）

| 方法 | 路径 | 谁能用 | 干什么 |
| ---- | ---- | ---- | ---- |
| `GET` | `/api/ai/agents` | 登录用户 | 列**自己的**智能体（admin 可带 `?scope=all` 看全部） |
| `POST` | `/api/ai/agents` | 登录用户 | 创建（属主 = 当前用户） |
| `GET` | `/api/ai/agents/:id` | 本人 / admin | 详情（**别人的私有智能体 ⇒ 404，不许泄露存在性**） |
| `PATCH` | `/api/ai/agents/:id` | 本人 / admin | 改（⚠️ 改 `system_prompt` 也要审计） |
| `DELETE` | `/api/ai/agents/:id` | 本人 / admin | 删 |

⚠️ **对外契约不变**：`core/routes/contract.ts` 的 9 个既有端点**一字不改** ⇒ 新端点是**加**，不是改。

## 4. 权限与审计

- **属主判定**用请求里的 JWT 用户 id ⇒ 与前端口径一致（前端 `access.ts` 的 `currentUser.access === 'admin'`）。
- **越权必须被拒绝**（403 / 404）⇒ **要有测试**（普通用户改别人的智能体 ⇒ 拒绝）。
- **审计**：创建 / 修改 / 删除各留一条（谁、何时、改了什么字段）⇒ 沿用 `core/audit/audit-trail.ts` 的形状。

## 5. 测试（改动要有测试）

- **单测**：CRUD 的正常路径 + 越权路径 + 审计落痕；
- **静态 e2e**（`scripts/e2e/` 下）：断言迁移里没有危险 SQL、断言新表是**只加不改**、断言 `contract.ts` 没被改；
- 跑得通：`cd backend/ai && npm test`、`npm run typecheck`、`node scripts/check-core-purity.cjs`、`node scripts/check-dsh-boundary.cjs`。
