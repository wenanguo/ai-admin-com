## 1. 口径（先说清楚「行数」怎么数）

⚠️ **本仓有两种行数口径** ⇒ 本清单**两个都写**，不混：

| 口径 | 怎么数 | `src/core` 合计 | 谁在用 |
| ---- | ------ | --------------- | ------ |
| **A · wc -l** | 数换行符（`s.match(/\n/g).length`） | **10 619** 行（71 个实现文件） | 仓库现有的减法守卫 `scripts/e2e/ai-subtraction.static.cjs`、PM 上面那张账 |
| **B · 有效代码行** | 去掉注释与空行后的行数 | **6 220** 行 | 本条 issue 里的「430 行」用的就是这个口径 |

> **「430 行」的来历**：issue 正文写「`runtime.ts` 剩下的 430 行」⇒ 那是**口径 B**
> （`runtime.ts` 实测：**630 行（口径 A）/ 429 行（口径 B）**）⇒ **不是数字变了，是口径不同**。
> ⇒ 下面每个文件都标 **A / B 两个数**（B 只在汇总与关键文件里给，避免表格太宽）。

⚠️ **不含测试**：本清单只盘**实现文件**（`*.ts` 且**不是** `*.test.ts`）⇒
测试（**8 106 行** / 51 个文件）**不在减法范围内**（测试是我们自己的质量资产，不是「重复实现」）。
