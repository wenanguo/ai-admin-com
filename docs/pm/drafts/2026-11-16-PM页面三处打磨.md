任务页与项目详情页三处**载入与提示的表现统一**：

## 上下文

### ① 甘特那条 Alert

`frontend/src/components/pm/task/TaskGantt.tsx:339-350`

```tsx
{mapping.excludedCount > 0 ? (
  <Alert type="info" showIcon
    title={`${mapping.excludedCount} 个任务没有计划起止日期,未显示`}
    description={`例如:${mapping.excludedTitles.join('、')}。给任务补上计划开始与截止日期后就会出现在甘特上。`} />
) : null}
```

⚠️ **为什么它是问题**：「任务没排计划日期」是**常态**（大多数任务本来就没排期）⇒
这条 Alert 会长期挂在甘特图顶部、**占掉整行把甘特图往下挤**，而且「未显示」这个措辞像在报故障。

### ② 任务列表的两个旋转

`frontend/src/components/pm/task/TaskListView.tsx:371-402` —— **自绘覆盖层**（居中 `Spin` +「载入中…」）
+ **ProTable 自带的 loading 遮罩** ⇒ 两个一起转。

⚠️ **不能简单删掉自绘的那个**（那是 issue #9 的成果，注释原话）：

> ProTable 自带的 loading 遮罩挂在**表格体**上 ⇒ 表格体还没数据时高度为 0 ⇒ 遮罩看不见
> ⇒ 用户只看到「空列表」⇒ 这里在视图层画一个覆盖层（居中 Spin + 半透明底）。

⇒ 真正的收敛点是：**让表格体有高度**（分页占位 / `scroll.y` / 最小高度）
⇒ ProTable 自带的遮罩就看得见了 ⇒ 就能删掉自绘的那个。
**参考实现**：里程碑页 `frontend/src/components/pm/milestone/MilestoneListView.tsx`
—— 它**只用 ProTable 自带的 loading，没有自绘覆盖层**。

### ③ 成员表没有载入指示

`frontend/src/pages/module_pm/project/detail.tsx:108-135`（`MembersTab`）
—— `useEffect` + `getProjectMembers(projectId)`，**没有 loading 状态** ⇒ 请求期间表格空白。

- 接口：`frontend/src/services/api/pm/project.ts:152` `getProjectMembers`
  （**返回的是数组**，不是分页信封 ⇒ `res?.data ?? []`）
- 成员表用的是 **antd `Table`**（不是 ProTable）⇒ **有原生 `loading` prop**，最省事的做法
- 姊妹页 `MembersTab` 之外的 tab（概览/里程碑/任务/风险）在同一文件里
