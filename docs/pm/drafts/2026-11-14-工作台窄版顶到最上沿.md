### 正文

```markdown
## 目标

AI 工作台的**两种形态顶边一致**：最大化（宽版浮层）和小窗口（右侧窄版）
**都顶到视口最上沿（y=0）**，不再一个 y=0、一个 y=56（顶栏下面）。

⚠️ **背景与方向（人定的）**：窄版**直接遮挡**顶栏右上角 ⇒ 顶栏里的用户头像/账号菜单
在窄版下会被盖住、点不到。**这是有意的**，不是遗漏：
人希望**后续这个界面可以拖动** ⇒ 先让面板能占满上沿（将来要能拖到视口任意位置），
所以这一版选择「直接遮挡」，不为了保住头像而留缺口。
⇒ 验收标准里已写明这条，**别当成 bug 改回去**。

## 验收标准

- [ ] **窄版顶边 y = 0**：右侧 400px 面板的 `boundingBox().y === 0`（与最大化一致）
- [ ] **最大化形态仍是 y = 0**（PR #58 的效果不被破坏；现有 e2e 守卫继续通过）
- [ ] ⚠️ **顶栏右上角被窄版覆盖，头像/账号菜单点不到 —— 这是有意的**（为将来「界面可拖动」铺路）
- [ ] 切换「最大化 ↔ 小窗口」时面板**不跳动**（沿用现有守卫）
- [ ] 滚动页面时面板**不动**（`position: fixed`，沿用现有守卫）
- [ ] **窄屏全宽（`width: 100vw`）时同样 y = 0**，且**不露半截 logo**
      （PR #58 用 `ai-workspace-header-patch` 处理过宽版的 logo，窄屏全宽要同样处理）
- [ ] ⚠️ **现有 e2e 断言必须同步改**：
      `frontend/e2e/ai-workspace.spec.ts` 里「初始：浮层的顶边在固定头部下面」
      （`expect(topBefore).toBeGreaterThan(0)`）**与新需求直接冲突** ⇒ 必须改成 y=0 的断言，否则必红
- [ ] **路由页 `/ai/workspace` 不受影响**（PR #58 的决策：它是独立页面，不动）
- [ ] 前端 `npm run lint` + `npm run test` 绿；相关 e2e 绿

## 范围

- 要做：
  - `AiWorkspaceShell.tsx` 里**窄版**的定位改为 `top: 0`（并把 `z-index` 与宽版对齐 ⇒ 101，
    否则顶栏与它同层时谁在上面取决于 DOM 顺序）
  - 按需处理窄屏全宽时的 logo 半截（参考 `ai-workspace-header-patch` 的做法）
  - 同步修改上面那条与之冲突的 e2e 断言
- 不做：
  - ❌ **不动最大化形态**（PR #58 已处理，别改回去）
  - ❌ **不动路由页 `/ai/workspace`**
  - ❌ 不改工作台的其它交互（命令卡片 / 待确认 / 审计面板 / 意图画廊）
  - ❌ 不重构 ProLayout 顶栏、不动 `avatarProps`
  - ❌ **不做「可拖动」** —— 那是后续单独的事；本条只把「能占满上沿」的地基打好
  - ❌ 不动 `backend/ai`

## 上下文

- **两种形态共用同一个组件实例**（切���只是外层盒子样式变 ⇒ 会话/SSE 不断）：
  `frontend/src/components/ai-workspace/AiWorkspaceShell.tsx`
  - **宽版（最大化）**：`position: fixed; top: 0; zIndex: 101` + `ai-workspace-header-patch`
    （PR #58 刚改，在飞）
  - **窄版（要改的）**：`position: fixed; top: headerHeight; right: 0; bottom: 0;
    width: narrow ? '100vw' : AI_WORKSPACE_WIDTH; zIndex: 100`
  - `headerHeight` 是本文件里的 state（实测顶栏高度，约 56）
- **e2e**：`frontend/e2e/ai-workspace.spec.ts`
  - 窄版守卫（约 1575 行起，`ai-workspace-panel`）
  - ⚠️ 「浮层的顶边在固定头部下面」断言（约 1639-1648）**与新需求冲突**
- **PR #58**（在飞）：`fix(ai): 最大化的工作台顶到视口最上面(盖住顶栏)`
  ⇒ 它的交接文档 `docs/notes/2026-11-14-ai-workspace-max-height.md` 里有完整决策记录
  （为什么抬 z-index、为什么要补 header patch、为什么路由页不动）
- **顶栏右上角有什么**：`frontend/src/app.tsx` 的 `avatarProps` ⇒ `AvatarDropdown`（头像 + 账号菜单 + 退出登录）
  ⇒ 窄版盖住顶栏 ⇒ 它被遮（本条**有意为之**）
- **ProLayout 顶栏**：`position: fixed; z-index: 100` ⇒ 浮层要盖住它必须 **z-index > 100**
```
