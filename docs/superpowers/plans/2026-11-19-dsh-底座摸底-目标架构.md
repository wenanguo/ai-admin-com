### 2.3 风险与回滚

| 风险 | 怎么办 |
| ---- | ------ |
| dsh 的事件名变了 | 只影响 `core/adapter/dsh/events.ts`（+ 单测会红） |
| 审批缝不通 | 退回「工具自己问」（spec §2.5）⇒ 闸门口径不变 |
| abort 没有协议对应 | D2 的结论落地（杀进程重建 / 进程内嵌入） |
| 流式体感退化 | D1 的结论落地；**契约不变 ⇒ 前端零改动** |

⇒ **回滚**：`git revert`（无数据迁移；`ai_*` 表不动）。
