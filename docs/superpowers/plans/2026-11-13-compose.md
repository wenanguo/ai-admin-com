# Docker Compose 编排 实施计划（2026-11-13）

> **给执行的 agent：** 建议用 superpowers:executing-plans 逐条执行本计划（任务少、彼此依赖明确，原生执行更省事）。
> 步骤用 `- [ ]` 复选框跟踪。

**目标：** 用 compose 把 #38 的前端镜像与 #39 的 AI 服务镜像串起来，nginx 做唯一公网入口，三条路由口径与开发期代理逐字一致。

**方案：** ① 编排：`docker/docker-compose.yaml`（web + ai、网络、日志、资源限制、healthcheck、端口只绑回环）+ `docker/.env.example`。② nginx 代理：把 server 块改成 **envsubst 模板**（`docker/web/templates/default.conf.template`），上游地址用环境变量注入 ⇒ 改地址不用重构建镜像。③ 验收：`scripts/e2e/compose.static.cjs`（静态断言）+ `scripts/e2e/compose.cjs`（真起 compose，含一个 **AiAdmin 桩**）+ CI workflow。

**技术栈：** Docker Compose v2 · nginx（envsubst 模板）· Node 22 · GitHub Actions。

**设计文档：** `docs/superpowers/specs/2026-11-13-compose-design.md`

## 全局约束

- **不直落 main**：全部改动走分支 `feat/40-compose` + PR。
- **不改 AiAdmin 那个仓**（只用 `AIADMIN_BASE_URL` / `AIADMIN_MCP_URL` 指向它）。
- **不做**：镜像构建（#38/#39 已做）、部署脚本（#D）、TLS/443、数据库/Redis 编排、数据库迁移。
- **不写真值**：`docker/.env` 不入库（已被 `**/.env` 忽略）；`.env.example` 只放占位。
- **验收脚本必须入库**（`.scratch/` 不算数）。
- **保持 #38/#39 的验收脚本仍然绿**（改了 nginx 配置 ⇒ `web-container.static.cjs` 要同步更新）。

## 评审重点

以下五个最可能咬人的情形，各由对应任务的步骤覆盖：

1. **`/api/` 被 rewrite**（路径被吃掉 ⇒ AiAdmin 404）⇒ 任务 3 的桩回显断言。
2. **`/ai-api/` 前缀没去掉**（AI 服务 404）⇒ 任务 4 的 `/ai-api/health` 断言。
3. **envsubst 变量未定义 ⇒ nginx 起不来** ⇒ 任务 2 的镜像 `ENV` 默认值 + 任务 4 的「独立跑镜像也能起」。
4. **AI 服务端口暴露到公网** ⇒ 任务 1 的 `127.0.0.1:` 端口绑定 + 任务 4 的 `compose port` 断言。
5. **真值混进 `.env.example`** ⇒ 任务 1 的静态断言。

### 任务 1：compose 编排 + `.env.example`

**涉及文件：**
- 新建：`docker/docker-compose.yaml`
- 新建：`docker/.env.example`

**接口：**
- 产出：服务名 `web`（镜像 `ai-admin-web`）与 `ai`（镜像 `ai-admin-ai`）；网络 `aiadmin`；
  环境变量清单 `WEB_PORT` / `AI_PORT` / `AIADMIN_PROXY_TARGET` / `AIADMIN_BASE_URL` / `AIADMIN_MCP_URL` /
  `DATABASE_URL` / `MINIMAX_CN_API_KEY` / `AI_MODEL` / `AI_THINKING_LEVEL` / `ALLOWED_ORIGINS`。

- [ ] **Step 1**：写 `docker/docker-compose.yaml`：
  - `web`：`image: ai-admin-web:latest` + `build: {context: .., dockerfile: docker/web/Dockerfile}`；
    `ports: ["${WEB_PORT:-8080}:80"]`；`environment: {AIADMIN_PROXY_TARGET: ..., AI_UPSTREAM: ai:3100}`；
    `depends_on: {ai: {condition: service_healthy}}`；healthcheck 打 `/healthz`；日志轮转；`mem_limit: 512m`；`cpus: 1.0`；`restart: unless-stopped`。
  - `ai`：`image: ai-admin-ai:latest` + `build: {context: .., dockerfile: backend/ai/Dockerfile}`；
    `ports: ["127.0.0.1:${AI_PORT:-3100}:3100"]`；`environment` 透传 AI 服务要的变量；
    healthcheck 打 `/health`；日志轮转；`mem_limit: 1g`；`cpus: 1.0`；`restart: unless-stopped`。
  - `networks: {aiadmin: {driver: bridge}}`；两个服务都接进去。
- [ ] **Step 2**：写 `docker/.env.example`：上表 10 个变量，全部占位/默认值，**每条带一行说明**；不含任何真值。
- [ ] **Step 3**：跑 `docker compose -f docker/docker-compose.yaml config`（**本机没 docker ⇒ 跳过，靠 CI**；至少人工核对 YAML 缩进）。
- [ ] **Step 4**：提交
  ```bash
  git add docker/docker-compose.yaml docker/.env.example
  git commit -m "feat(docker): compose 编排（web + ai，nginx 唯一入口，AI 只绑回环）"
  ```

### 任务 2：nginx 拆成「主配置 + 模板」（为可配上游铺路）

**涉及文件：**
- 修改：`docker/web/nginx.conf`（server 块移出，改成 `include /etc/nginx/conf.d/*.conf;`）
- 新建：`docker/web/templates/default.conf.template`
- 修改：`docker/web/Dockerfile`（拷模板 + `ENV` 默认值）

**接口：**
- 消费：任务 1 的 `AIADMIN_PROXY_TARGET` / `AI_UPSTREAM`。
- 产出：镜像启动时由 nginx 官方 entrypoint 的 envsubst 生成 `/etc/nginx/conf.d/default.conf`；
  环境变量 `AIADMIN_PROXY_TARGET`（默认 `https://www.pmdict.cn`）、`AI_UPSTREAM`（默认 `127.0.0.1:3100`）。

- [ ] **Step 1**：把 `docker/web/nginx.conf` 里的 `server { ... }` 整块挪到新文件 `docker/web/templates/default.conf.template`；
  主配置只留 http 层（logs / gzip / `server_tokens off` / `include /etc/nginx/conf.d/*.conf;`）。
- [ ] **Step 2**：模板里写三条路由：
  - `/api/` ⇒ `proxy_pass ${AIADMIN_PROXY_TARGET};`（**不带 URI 部分** ⇒ 不 rewrite）+ 透传 Host/X-Real-IP/X-Forwarded-*。
  - `/ai-api/` ⇒ `proxy_pass http://${AI_UPSTREAM}/;`（**带 `/`** ⇒ 去前缀）+ SSE 指令（`proxy_http_version 1.1`、
    `proxy_set_header Connection ''`、`proxy_buffering off`、`proxy_cache off`、`proxy_read_timeout 3600s`、`proxy_send_timeout 3600s`）。
  - `/` ⇒ 静态 + `try_files $uri /index.html;`；外加 `/healthz`、`/index.html`、`/assets/`、静态资源正则（照搬 #38 的）。
- [ ] **Step 3**：模板里每个自带 `add_header` 的 location 都 `include /etc/nginx/snippets/security-headers.conf;`（继承坑）。
- [ ] **Step 4**：改 `docker/web/Dockerfile`：`COPY docker/web/templates/ /etc/nginx/templates/`；
  加 `ENV AIADMIN_PROXY_TARGET=https://www.pmdict.cn AI_UPSTREAM=127.0.0.1:3100`。
- [ ] **Step 5**：更新 `scripts/e2e/web-container.static.cjs`（#38 的）：server 块的断言改到**模板文件**上读；
  断言模板里含 `${AIADMIN_PROXY_TARGET}` / `${AI_UPSTREAM}`，且 Dockerfile 里有对应的 `ENV` 默认值。
- [ ] **Step 6**：跑 `node scripts/e2e/web-container.static.cjs` ⇒ 全绿。
- [ ] **Step 7**：提交
  ```bash
  git add docker/web/nginx.conf docker/web/templates docker/web/Dockerfile scripts/e2e/web-container.static.cjs
  git commit -m "feat(docker): nginx 拆主配置 + 模板（上游地址可用环境变量替换）"
  ```
