## 决策记录（★ 最值钱的部分）

| 决定 | 为什么 | 错了的代价 |
| ---- | ------ | ---------- |
| **自研命令改名 `pm_create_task`，不删** | ① 删它 ⇒ 连带删 `adapter/datasource.ts` + `model.ts` + `keys.ts` + `enums.ts`（≈ 2 000 行）⇒ **超出这条 issue 的规模**，且属于减法摸底 #180 的活；② 它的独有能力是「**项目编码 → id**」（MCP 没有列项目工具 ⇒ 换不了）⇒ 删了这条能力就没了 | 删 ⇒ 一条「中」规模的单变成跨模块大重构 ⇒ 评审周期拉长、能力倒退 |
| **技能只教 **MCP** 的工具**，不教自研命令 | issue「不做」栏明写：**不给普通业务命令补齐到技能里**（那条主张是「后端加接口，AI 侧不用改代码」）⇒ 自研命令进技能就是破这条主张 | 把自研命令写进技能 ⇒ 能力又回到 AI 侧 ⇒ 后端加接口仍要改 AI 侧 ⇒ 主张破 |
| **快照入仓 + 离线守卫**（而不是每次在线拉） | CI 里**没有** AiAdmin ⇒ 在线校验跑不了 ⇒ 只能「人工抓一次 · 入库 · CI 离线比对」⇒ **漂移在 CI 里红** | 改成 CI 里在线拉 ⇒ 要凭据 ⇒ CI 变脆；或干脆不校验 ⇒ 又回到「悄悄失配」 |
| **守卫自带负例自测**（改坏快照 ⇒ 必红） | 不然没人知道守卫是不是摆设 ⇒ 一条「看着很严」的假守卫比没有更坏 | 没负例 ⇒ 守卫可能一直是空转的 ⇒ 大家以为有防护 |
| **技能参数表写成**可机检的 markdown 表（`| 参数 | 类型 | 必填 | 说明 |`） | 「人能读」是提示词的基本要求；「机器能读」才能比对 schema ⇒ 一张表同时满足两边 | 只写散文 ⇒ 守卫没法比 ⇒ 又回到人工核对 ⇒ 迟早漂 |
| **必填以 schema 为准**（`patch_task_status` 的 `ids` / `status` **都不标必填**） | 快照里那个工具**没有 `required`** ⇒ 标了必填就是与真实 schema 不符 ⇒ 守卫会红 | 按「语义上必须」标必填 ⇒ 守卫天天红 ⇒ 大家就学会忽略守卫 |
| **闸门口径一个字没改**，只补了**逐工具核对**的单测 | 这条 issue 的验收写明「闸门口径不变」⇒ 口径只有一份（`core/gate/gate.ts`）⇒ 用它来核对快照里每个工具的结论，而不是另写一套 | 顺手改口径 ⇒ 高风险 ⇒ 要人拍板；或复制一份口径 ⇒ 两份会漂 |
| **PR base = `main`** | `agent/pm-dev-182` 这个分支**远端没有** ⇒ 不能当 base；仓库惯例：开发 agent 的 PR 一律提 `main`（#185 / #187 都是） | 提到不存在的分支 ⇒ PR 建不出来 |

## 坑与提醒

- ⚠️ **MCP 工具**（模型侧 `mcp__aiadmin__xxx`）**不受**智能体 `tools:` 白名单管
  ⇒ 白名单只管**插件命令** ⇒ 改白名单**不会**关掉 MCP 工具。
- ⚠️ **`create_task` 这个裸名现在只指 MCP 那个** ⇒ 我们的自研命令改成了 `pm_create_task`
  ⇒ **审计里的 `command` 字段**也跟着变了（`pm_create_task`）⇒ 查历史审计别用旧名字。
- ⚠️ **MCP 没有「列项目」工具**（只有 5 个任务工具）⇒ 用户只给**项目编码**时，
  走 MCP 的建任务这条路**走不通** ⇒ 技能里写的是「问用户要数字 id / 绝不编 id」。
  ⇒ **能力缺口**：要后端加 `list_projects`（**AiAdmin 那个仓**的活，本仓不改）。
- ⚠️ **后端 `patch_task_status` 自相矛盾**：描述说「`status_code` 取字典值」，
  **schema 是 `status`：整数 0/1**（= 是否可用）⇒ 以 schema 为准；而且它的 `status`
  **默认值是 0（停用）** ⇒ 技能里写了「必须显式传」。
- ⚠️ **优先级字典码是**大写 `P0`~`P3`**（类型 / 状态才是小写）⇒
  `docs/ai-architecture.md` 里有一处写成小写 `p0` ⇒ 已改。
- ⚠️ **这台机器内存很紧**（16 GB 里只剩 ~1.3 GB）⇒ `vitest run` 并行跑会 **OOM**
  ⇒ 加 `--no-file-parallelism`；`npm run typecheck` 也会被 npm 包装器的 OOM 弄挂
  ⇒ 直接 `node node_modules/typescript/bin/tsc --noEmit`。
- ⚠️ **`src/plugins/**` 只有 `src/plugins.ts`（入口侧）能 import** ⇒
  测试里也要从 `./plugins.ts` 拿插件 ⇒ 直接 import `./plugins/pm/index.ts`
  ⇒ `scripts/e2e/dsh-skills-mcp-plugins.static.cjs` 会红。
- ⚠️ **`.pi/skills/**` 是提示词** ⇒ 进模型上下文 ⇒ 走 git 评审（AGENTS.md 的硬规矩）。
- ⚠️ **本 PR 只开不合并**（用户明确要求）⇒ 等人拍板后再合。
