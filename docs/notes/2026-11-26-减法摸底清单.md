## 坑与提醒

- ⚠️ **数行数用 node**（`(s.match(/\n/g)||[]).length` = wc -l）：
  `Get-Content .Count` 在中文文件上会**吞掉换行** ⇒ 数出来偏小（本仓笔记里踩过）。
- ⚠️ **`session/query` 不是历史查询** —— 它是「把输入当命令跑一遍并等它结束」⇒
  **别被名字骗了**（这是 D2 边界最容易被绕过的地方）。
- ⚠️ **dsh 的注册表原生收 raw JSON Schema**（`dsh-llm` 的 `ToolSchema.parameters` 就是
  `Record<string, unknown>`；`dsh-mcp-client` 直接 `parameters: inputSchema`）⇒
  **但** `defineTool()` 要的是 dsh 的 **DSL** ⇒ 换法是「注册 raw `ToolDefinition`」，不是「把 JSON Schema 塞进 `defineTool`」。
- ⚠️ **`dsh-user-approval` 不判断「哪个工具要点头」**（README：*the service itself never prompts a human*）
  ⇒ 闸门口径退不回去；`dsh-permission-presets` 只是 *owns selection, not enforcement*。
- ⚠️ **本仓有第二份闸门口径**：`backend/ai/dsh-plugin/src/mcp.js` 的 `registerGate()` 里硬编码了
  `update_` / `patch_` ⇒ ask ⇒ 与 `core/gate/gate.ts` 冲突 ⇒ **不在 `src/core` 范围内，但同源** ⇒ 建议单开一条。
- ⚠️ **清单的表格里别写 `|`**（验收脚本按 `|` 分格）⇒ 分类那一格也只能写三个词之一
  （脚本会去掉 markdown 强调，但**不接受**「必须留（含死配置）」这种带后缀的写法）。
- ⚠️ **本 PR 的 PR base 是 `main`**（`agent/pm-dev-180` 这个分支**远端没有** ⇒ 不能当 base；
  仓库惯例：开发 agent 的 PR 一律提 `main`，`Closes #180` 才能自动关单）。
