# dsh 的凭据配在哪（issue #123 收尾）

## 一句话

**写在 `backend/ai/.env`**（那个文件已被 gitignore）⇒ **服务与 PM 派活都用它**。

```bash
# backend/ai/.env
DEEPSEEK_API_KEY=sk-你的官方key
```

## 变量名的三套叫法（别搞混）

| 位置 | 读什么 | 说明 |
| ---- | ------ | ---- |
| **AI 服务**（`src/core/adapter/dsh/runner.ts`） | `AI_DSH_BASE_URL`（缺省官方）· `AI_DSH_MODEL`（`deepseek-chat`）· `AI_DSH_PROVIDER`（`deepseek-direct`）· `AI_DSH_API_KEY_ENV`（**key 放在哪个变量里**，缺省 `DEEPSEEK_API_KEY`） | `.env` 由 `src/core/env/load-env.ts` 加载 ⇒ **必须在 `backend/ai/` 下启动服务** |
| **dsh 子进程**（`dsh-plugin/src/index.js`） | `AI_DSH_PROVIDER` / `AI_DSH_MODEL` / `AI_DSH_BASE_URL` / `AI_DSH_API_KEY` | **由服务翻译过去**（`runner.ts` 拼好再 spawn）⇒ 人**不用**直接配这四个 |
| **PM 派活**（`scripts/agent/lib/dsh-dispatch.cjs`） | `DISPATCH_PROVIDER` / `DISPATCH_MODEL` / `DISPATCH_BASE_URL` / `DISPATCH_API_KEY`（`DISPATCH_API_KEY_ENV` 改名） | ⚠️ **也读 `backend/ai/.env`** ⇒ 一把 key 两处用 |

## 派活的路由怎么选

```
显式 DISPATCH_PROVIDER ⇒ 听它的（模型与地址**跟着**它变 ⇒ 不会配错）
否则有 DEEPSEEK_API_KEY ⇒ 官方（deepseek-direct / deepseek-chat / https://api.deepseek.com/v1）
否则有 MINIMAX_CN_API_KEY ⇒ minimax / MiniMax-M3.1-Flash / https://api.minimaxi.com/v1
```

## 两条规矩

1. **凭据只在内存里**：只进子进程的 `AI_DSH_API_KEY`（`buildChildEnv` 里有测试盯着）⇒ 不落盘、不进日志。
2. **派活彻底不碰 pi**：连 pi 的 `auth.json` 都不借了（issue #123 收尾）⇒ 没有 key 就**报清楚**，
   不猜、不偷用别的凭据。

## ⚠️ 变量名为什么都带 `AI_` 前缀（issue #124 阶段三抓到的真 bug）

dsh 的 app-boot 里有 `BOOTSTRAP_PREFIXES = ['DSH_', 'XDG_', 'DYLD_', 'BASH_FUNC_']`
⇒ **任何 `.env` 文件里写 `DSH_*`，dsh 都拒绝启动**：

```
dsh: …/.env sets "DSH_BASE_URL", which only the launching environment may set
```

而 dsh 会读**它启动目录**的 `.env`（`backend/ai/.env` 正是那个位置）
⇒ 我们的 `.env.example` 原来教人写 `DSH_BASE_URL` ⇒ **照着配就炸**。

⇒ 现在的口径（2026-11-23 起）：

| 谁的名字 | 例子 | 出现在哪 |
| ---- | ---- | ---- |
| **用户可配的**（我们的） | `AI_DSH_BASE_URL` / `AI_DSH_MODEL` / `AI_DSH_ADMIN_ENABLED` … | `.env` ✅ |
| **dsh 自己认的** | `DSH_HOME` / `DSH_PERMISSION_MODE` | **只**在子进程的**进程环境**里（✅），`.env` 里 ❌ |
| **插件读的**（我们起子进程时翻译过去） | `AI_DSH_PROVIDER` / `AI_DSH_TOOLS` / `AI_DSH_BRIDGE_URL` … | 只进子进程环境 |

⚠️ 旧的 `DSH_*` / `DSH_AI_*` 名字**不再被读**（`runner.test.ts` 有测试钉住 —— 别为了「兼容」读回来，
读回来就等于又教人去 `.env` 里写 `DSH_*`）。
