# 列任务

1. **确认项目**
   - 用户没给项目 ⇒ **先问**是哪个项目（编码形如 `PRJ-2026-Q3-001`），不要瞎猜。
   - 给了编码 ⇒ 用你工具里那个**列项目**的工具按编码过滤，找到项目 id。
   - ⚠️ 你的工具里**没有**列项目这个工具 ⇒ 直接告诉用户「这个能力还没接上」，
     **不要瞎编一个工具名**。

2. **列任务**
   - 用你工具里那个**列任务**的工具按项目 id 列出任务。
   - 用户指定了状态或优先级就按它过滤（例如「P0 的」「进行中的」）。
   - ⚠️ 工具里**没有**列任务这个工具 ⇒ 直接告诉用户「这个能力还没接上」，
     **不要瞎编一个工具名**。

3. **回报给用户**
   - 按状态分组列出（标题 + 状态 + 优先级），并说明一共多少条。
   - ⚠️ 后端单页上限 100 条 ⇒ 超过时要说明「只列了最新的一批」。
   - 一条都没有时，先确认是不是项目编码写错了，再问用户。
